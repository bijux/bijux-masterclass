# Lab Oracles

The lab oracle is the smallest fact that answers the engineering question.

| Module | Decisive oracle |
|---:|---|
| 1 | intended endpoint addition has no unrelated replacement or deletion |
| 2 | foreign lineage and concurrent mutation are rejected before state write |
| 3 | module extraction preserves remote identity and exposes a narrow API |
| 4 | compromised workload cannot mutate organization policy or delete audit authority |
| 5 | route selection and security boundaries match the declared packet path |
| 6 | required action succeeds and adjacent unauthorized action is denied |
| 7 | new host uses approved image/identity and restores durable facts without old root disk |
| 8 | TLS path is exclusive and empty restore reproduces acknowledged result |
| 9 | explicit moves/import preserve IDs and emergency drift remains visible |
| 10 | only a source/plan/policy/target-bound candidate receives the bounded release status |

A learner can produce many files and still fail if the decisive oracle is
missing.
