# Runbook — Partial Apply

1. Stop promotion and retain the saved plan, apply transcript, state version,
   and role session identity.
2. Inventory what was actually created or changed.
3. Check for public exposure, key/identity changes, and ongoing cost.
4. Contain urgent risk without deleting state bindings blindly.
5. Run a new plan from current reality.
6. Decide roll-forward, controlled cleanup, or recovery from a protected state
   version.
7. Execute the selected action with peer review.
8. Run all affected data-plane proofs.
9. Record final resource inventory and cleanup.
