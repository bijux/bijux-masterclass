# Predecessor Handoff

Course 2 consumes the exact nine-file handoff exported by Course 1 under `capstone/predecessor/`.

The handoff defines:

- Atlas Host Runtime Profile 1.0;
- network and storage behavior;
- known failure scenarios;
- provider vocabulary mappings;
- fourteen cloud-foundation requirements;
- a handoff schema;
- a version ledger.

Course 2 may choose provider-specific mechanisms. It may not silently weaken the required behavior. Any deliberate change requires a new versioned requirements package and a migration note.
