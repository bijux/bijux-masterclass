# Assessment Rubric

| Dimension | Points | Evidence |
|---|---:|---|
| declarative model and plan reasoning | 10 | address graph, action classification, saved-plan binding |
| state safety and recovery | 15 | backend profile, lock/lineage proof, recovery drill |
| module and composition design | 10 | typed interfaces, flat composition, version migration |
| landing-zone and identity boundaries | 10 | account/role model, policy vectors, break-glass design |
| network and edge correctness | 15 | CIDR/route proof, security path, DNS/TLS evidence |
| compute replacement and data recovery | 15 | image/launch contract, restore-to-empty evidence |
| drift and migration discipline | 10 | classified differences, moved/import records |
| delivery and release evidence | 10 | plan/policy/target binding, candidate decisions |
| communication and honest limits | 5 | precise claims and evidence classes |
| **Total** | **100** | |

A score of 85 is required. State safety, public exposure, identity, data
recovery, and evidence honesty are non-compensable.
