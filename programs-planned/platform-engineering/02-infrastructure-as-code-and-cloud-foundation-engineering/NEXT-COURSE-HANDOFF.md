# Course 2 → Course 3 Handoff

Course 3, Container, OCI, and Software Supply Chain Engineering, receives the cloud foundation but not an assumption that machine bootstrapping is the final workload-delivery mechanism.

The handoff includes:

- image and architecture requirements;
- workload identity and metadata constraints;
- network exposure and egress contracts;
- immutable release and replacement rules;
- storage and backup boundaries;
- artifact registry requirements;
- provenance, SBOM, and signing requirements for the next course;
- exact infrastructure version and evidence ledger.

Course 3 will replace mutable host payload installation with governed OCI artifacts while preserving the cloud foundation.
