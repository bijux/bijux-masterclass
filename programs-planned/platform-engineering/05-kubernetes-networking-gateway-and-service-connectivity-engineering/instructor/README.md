# Instructor material

The instructor lane supports facilitation; it is not the source of learner theory. The authoritative explanations remain in `course-book/`.

Use the planted-defect map, final-defense rubric, and review questions to test reasoning across layers. Do not reveal the injected layer before the learner writes a packet path and a falsifiable hypothesis. Preserve a failure long enough to collect control-plane, data-plane, transport, and protocol evidence.

Optional infrastructure laboratories must use isolated, disposable environments. A learner who lacks kind or a cloud account can complete the dependency-light lane, but must mark cluster and environment claims as not executed. A learner with a cluster must still complete the semantic lane rather than replacing reasoning with tool output.
