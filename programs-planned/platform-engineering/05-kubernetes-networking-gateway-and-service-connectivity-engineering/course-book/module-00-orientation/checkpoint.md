# Orientation checkpoint

## Required evidence

- exact Course 4 predecessor proof;
- three complete packet-path ledgers;
- one address-domain inventory;
- required/optional tool report;
- explicit evidence boundary;
- no changes to predecessor files.

## Decision defense

Defend which guarantees are inherited and which networking claims remain unproven. Explain why the course cannot begin by applying a Gateway manifest and calling the application connected.

## Progression gate

Proceed to Module 1 only when the predecessor remains byte-identical and every path transition has a named owner or an explicit unresolved question.
