# Conformance evidence

A conformance claim records:

```text
feature/resource
specification and version
implementation and version
profile/channel
configuration
environment/topology
positive tests
negative tests
status conditions
known deviations
evidence artifacts
```

Examples:

- CNI specification lifecycle support;
- Kubernetes NetworkPolicy enforcement;
- Gateway API Core profile and selected features;
- Service traffic-policy behavior;
- DNS record behavior.

Static parsing is not conformance. One implementation result should not be generalized to every implementation or environment.
