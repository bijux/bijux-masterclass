# Instructor review questions

Use these questions across modules:

- Which object expresses intent, and which implementation makes it real?
- What state can remain healthy while this transition fails?
- Where is the packet before and after translation?
- Which identity does the next component actually trust?
- What negative control proves the evidence is sensitive?
- Is this behavior standardized, course-profiled, or implementation-specific?
- What survives a controller or node restart?
- What evidence class supports the conclusion?
- Which claim remains unexecuted?
- What exactly must Course 6 inherit?
