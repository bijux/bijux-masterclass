# Instructor facilitation guide

The instructor should not reveal the injected layer before the learner writes a hypothesis. Ask for the expected packet path, earliest possible failed transition, and one falsifying observation.

When a learner reaches for a restart or deletion, require an explanation of which state the action changes and what evidence will be lost. Preserve failures long enough to collect control-plane and data-plane evidence.

Use environment boundaries explicitly. A learner without a local cluster can still complete the semantic lane; a learner with a cluster must not skip the models. The strongest discussions compare where the semantic contract and installed implementation differ.
