# Ten-Course Journey

| Course | Responsibility | Atlas result |
|---:|---|---|
| 1 | Linux, networking, and cloud systems | Operable host profile and cloud-foundation requirements |
| 2 | Infrastructure as code and cloud foundation | Reproducible accounts, networks, IAM, compute, storage, and state |
| 3 | Containers, OCI, and supply chain | Immutable workload artifacts with provenance |
| 4 | Kubernetes architecture and workloads | Declarative workload runtime |
| 5 | Kubernetes networking and gateways | Governed service connectivity and exposure |
| 6 | Kubernetes storage and data resilience | Persistent workload and recovery model |
| 7 | GitOps and release engineering | Reviewed desired state and safe promotion |
| 8 | Platform security and multi-tenancy | Enforced workload, identity, network, and artifact policy |
| 9 | Reliability, observability, capacity, and fleet | Operable cluster fleet with explicit service objectives |
| 10 | Internal developer platform and control plane | Self-service platform capabilities with product ownership |

The order matters. Each abstraction hides details that the learner must first understand well enough to debug when the abstraction leaks.
