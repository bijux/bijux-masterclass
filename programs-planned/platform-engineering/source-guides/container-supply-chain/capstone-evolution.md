# Atlas capstone evolution

```text
Course 1 — Atlas Host Runtime 1.0
    Processes, files, signals, sockets, TLS, durable host state

Course 2 — Atlas Cloud Foundation 1.0
    Governed accounts, network, identity, compute, data protection, remote state

Course 3 — Atlas Workload Release 1.0
    Multi-platform OCI images, registry distribution, runtime profile, SBOM,
    vulnerability decisions, provenance, signatures, and promotion policy

Course 4 — Atlas Kubernetes Workload 1.0
    Declarative scheduling and reconciliation of the verified Course 3 release
```

Each transition preserves the previous contract while changing who reconciles it.
