# Atlas Capstone Evolution

Atlas begins as a small production-shaped workload: an HTTP API accepts jobs, a worker processes them, durable files hold queue and result state, and an HTTPS edge exposes only the intended surface.

Course 1 operates that workload directly on Linux. Course 2 turns the host requirements into cloud infrastructure. Course 3 packages the workload as OCI images. Courses 4–9 progressively orchestrate, connect, persist, deliver, defend, and operate it. Course 10 exposes a governed `Application` capability to developers.

The application is deliberately small. The platform responsibilities are not.
