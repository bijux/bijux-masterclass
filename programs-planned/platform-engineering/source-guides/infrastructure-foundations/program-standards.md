# Program Standards Policy

The program separates four classes of statement:

1. **Normative standard:** POSIX, IETF RFC, OCI, Kubernetes, or another published specification.
2. **Platform contract:** a rule Atlas deliberately promises.
3. **Reference implementation behavior:** a documented property of a selected tool or provider.
4. **Course profile:** a bounded choice made to keep exercises reproducible.

A course profile must not be presented as a universal standard. Tool behavior must be verified against the pinned release or official documentation used by the course.
