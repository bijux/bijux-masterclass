# Program standards policy

The program distinguishes normative upstream APIs, Atlas platform contracts, pinned implementation behavior, and bounded teaching profiles. Course 5 inherits Kubernetes 1.36.2, uses CNI specification 1.1.0, Gateway API 1.6.1 Standard Channel, and CoreDNS 1.14.6 as the reference profile. Cilium 1.20.0 is the optional local implementation lane, not the definition of Kubernetes networking.
