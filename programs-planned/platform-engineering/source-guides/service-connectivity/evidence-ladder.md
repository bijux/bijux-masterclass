# Program evidence ladder

The program separates document evidence, semantic evidence, local mechanism evidence, cluster evidence, cloud environment evidence, and operated evidence.

A deterministic Service selector can prove that not-ready endpoints are excluded under the Atlas contract. A loopback TLS gateway can prove hostname verification and trusted-header replacement. Neither proves that a particular CNI, cloud load balancer, Gateway controller, or multi-zone environment behaves identically.

Progress depends on the strongest claim being supported by the correct evidence class. Unavailable infrastructure is reported as unavailable, not converted into success.
