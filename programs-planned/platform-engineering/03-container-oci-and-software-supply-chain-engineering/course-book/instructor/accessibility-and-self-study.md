# Accessibility and self-study support

- All diagrams have a textual equivalent in the surrounding chapter.
- Labs use explicit setup, action, oracle, evidence, cleanup, and gate headings.
- Commands are optional evidence lanes when equivalent semantic artifacts are available.
- Learners may choose a primary native toolchain; product-specific duplication is not required.
- Long sessions should be split at object boundaries rather than arbitrary page counts.
- Answers explain reasoning so a self-learner can compare without an instructor.
- Evidence reports should be machine-readable where possible and accompanied by a concise interpretation.
- Privileged labs are never mandatory for understanding; their missing evidence is recorded honestly.

For learners using non-Linux hosts, recommend a disposable Linux VM. Do not silently substitute Docker Desktop behavior for direct Linux namespace/runtime evidence; label the virtualization layer.
