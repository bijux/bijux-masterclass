# Orientation checkpoint

## Required evidence

- complete predecessor obligation map;
- source-to-runtime release trace;
- successful capstone tour report;
- one intentional digest failure;
- written evidence-boundary statement.

## Decision defense

Defend this claim:

> A runnable image is weaker evidence than an authorized release.

Your defense must mention runtime compatibility, subject binding, build provenance, and promotion policy.

## Progression gate

Proceed only when you can distinguish these without notes:

- process;
- container;
- runtime bundle;
- image manifest;
- image index;
- registry repository;
- tag;
- digest;
- attestation;
- release decision.
