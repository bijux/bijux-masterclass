# Checkpoint — Distribution and registry

## Required evidence

- successful push/pull of all Atlas indexes;
- exact digest verification;
- tag-movement experiment;
- subject-specific referrer inventory;
- repository authority matrix;
- retention/GC decision record.

## Decision defense

Defend which tags Atlas will publish and why none of them is accepted as deployment authority.

## Progression gate

Proceed when distribution and release authorization are clearly separated. Module 7 will evaluate whether the approved image can run under a least-authority operational profile.
