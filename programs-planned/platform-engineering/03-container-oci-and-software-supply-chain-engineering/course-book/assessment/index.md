# Assessment

Assessment in this course is evidence based. Remembered command syntax earns little credit unless it supports a correct object model, a defensible decision, and a reproducible oracle.

## Components

- [Knowledge check](knowledge-check.md) tests whether the core distinctions survive without the capstone open beside you.
- [Practical assessment](practical-assessment.md) asks you to repair a deliberately inconsistent workload release without weakening the Course 2 contract.
- [Final defense](final-defense.md) requires a live argument from exact source and image subjects through runtime and supply-chain evidence to the Course 4 handoff.
- [Rubric](rubric.md) defines non-compensable gates and the difference between a passing mechanism demonstration and an elite engineering defense.

## What a complete answer contains

A strong answer normally includes:

1. the exact subject or state being discussed;
2. the mechanism that governs it;
3. the failure mode excluded by the mechanism;
4. the evidence and oracle;
5. the boundary of the claim;
6. the decision and residual risk.

A weak answer names a tool, repeats a best practice, or reports a green command without showing what that command was capable of falsifying.
