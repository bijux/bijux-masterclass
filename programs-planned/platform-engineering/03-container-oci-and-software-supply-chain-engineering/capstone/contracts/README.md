# Course profiles and contracts

These JSON documents are Atlas platform policy, not OCI standards:

- `build-profile.json` defines controlled build inputs and evidence classes;
- `runtime-profile.json` defines workload identity, mounts, lifecycle, and authority;
- `artifact-types.json` defines course evidence artifact types;
- `release-policy.json` defines non-compensable promotion gates.

Changes require a release-candidate test showing whether the new profile is additive, review-required, or breaking for Course 4.
