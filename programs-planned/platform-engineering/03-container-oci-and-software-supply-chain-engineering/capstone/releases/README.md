# Release decision corpus

`accepted/release.json` is regenerated by the checked capstone tour. The other directories contain deliberately failing, review-required, or not-executed candidates. They test whether release policy can reject attractive but invalid evidence.

A candidate status is categorical. A rejected identity/runtime/secret/subject gate cannot be offset by strong scores elsewhere. `review-required` identifies a decision that needs owned evidence; `not-executed` identifies an environment proof that was unavailable.
