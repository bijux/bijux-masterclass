# Linux, Networking, and Cloud Systems Engineering

Course 1 of the Platform Engineering program.

This course builds and operates **Atlas Host Runtime 1.0** on Linux. It teaches the machine and network substrate beneath containers, Kubernetes, and cloud platforms, then exports exact requirements for Course 2 to encode as infrastructure.

## Primary product

Read the [course book](course-book/start-here.md). The capstone and proof routes exist to make the explanations executable.

## Stable entrypoints

```bash
make help
make doctor
make core-proof
make capstone-tour
make manifest-proof
```

Linux-, privilege-, VM-, and cloud-backed routes are separate and never converted into synthetic passes when the required environment is absent.

## Release evidence

The exact executed and environment-backed proof boundary is recorded in [`FINAL-VERIFICATION.md`](FINAL-VERIFICATION.md). The checked-in PKI material is a public fixture and must never be reused as a real credential.
