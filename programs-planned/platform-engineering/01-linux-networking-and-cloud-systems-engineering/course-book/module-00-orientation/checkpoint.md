# Orientation Checkpoint

Submit or retain:

- host and tool inventory;
- evidence-class decision;
- passing dependency-light proof transcript;
- passing Atlas tour report;
- post-clean process and filesystem check;
- disposable-VM safety and recovery plan;
- a statement that course fixture private keys and cloud credentials will never be reused or committed.

Do not begin Module 01 if the current environment is ambiguous, cleanup is incomplete, or privileged labs have no recovery route.
