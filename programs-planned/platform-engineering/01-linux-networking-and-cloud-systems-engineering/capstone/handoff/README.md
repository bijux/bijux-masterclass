# Course 1 → Course 2 Handoff

This directory is the immutable provider-neutral input to Infrastructure as Code and Cloud Foundation Engineering. It defines Atlas Host Runtime Profile 1.0, network and storage behavior, failure scenarios, provider mappings, fourteen testable cloud-foundation requirements, a schema, and a version ledger.

Course 2 must map these requirements to real resources and state. A provider product name is not acceptance evidence. Any behavioral change requires a versioned requirements revision.
