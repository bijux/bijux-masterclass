# Final project — defend Atlas Kubernetes Runtime 1.0

The learner submits one evidence directory containing:

- exact predecessor verification;
- production-intent manifest inventory and digests;
- semantic controller convergence report;
- Go controller test output;
- one rollout calculation;
- one unschedulable Pod explanation;
- one probe and shutdown decision;
- one finalizer failure and repair;
- one rejected controller choice;
- exact Course 5 handoff verification.

The submission must distinguish dependency-light, local-cluster, and unexecuted environment-backed evidence.
