# Deferred responsibilities

Course 4 intentionally does not claim mastery of:

- CNI packet forwarding, kube-proxy/eBPF data planes, DNS behavior, Gateway API, ingress, egress, or service mesh — Course 5;
- CSI, StorageClasses, snapshots, backup/restore, Stateful workload data safety — Course 6;
- Helm, Kustomize, GitOps, promotion, rollback automation — Course 7;
- cluster security, admission policy, multi-tenancy, image-policy enforcement — Course 8;
- fleet SLOs, autoscaling, upgrades, capacity and cost — Course 9;
- platform APIs, Crossplane, developer portals, self-service — Course 10.

Objects may be introduced as interfaces for handoff. Their deeper guarantees must remain unclaimed until the owning course.
