# Production claims and evidence boundary

Atlas Kubernetes Workload 1.0 is a release-oriented educational reference. It proves object semantics, controller decisions, manifest structure, dependency-light reconciliation, and—when available—a pinned local kind topology.

It does not claim production control-plane availability, managed-cluster identity integration, multi-zone survival, production CNI/CSI/Gateway behavior, representative capacity, cluster-upgrade evidence, or operated disaster recovery. Courses 5–9 own those responsibilities.
