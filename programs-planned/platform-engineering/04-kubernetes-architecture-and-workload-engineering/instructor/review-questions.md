# Instructor review questions

Use these questions when a learner presents a repair:

1. Which object held the desired state?
2. Which component owned the missing transition?
3. What was the earliest contradictory observation?
4. Which identity—name, UID, digest, field manager, or logical effect ID—was decisive?
5. Did the repair change an owning input or merely repeat the same state?
6. Which evidence was captured before mutation?
7. What later course owns the unresolved networking, storage, security, delivery, or fleet claim?
