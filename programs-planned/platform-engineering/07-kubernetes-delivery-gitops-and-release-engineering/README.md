# Course 7 — Kubernetes Delivery, GitOps, and Release Engineering

This course teaches how reviewed source revisions become observable Kubernetes desired state without weakening the storage, security, workload, and networking guarantees established in Courses 1–6.

The learner builds **Atlas Delivery Plane 1.0** from the exact Course 6 handoff. The result includes deterministic rendering, inventory-aware reconciliation, protected-resource policy, environment promotion by immutable identity, Argo CD and Flux reference lanes, secret-delivery boundaries, progressive-delivery decisions, multi-cluster release choreography, incident recovery, and an exact handoff to Course 8.

Start at [`course-book/start-here.md`](course-book/start-here.md).

```bash
make help
make doctor
make predecessor-proof
make core-proof
make capstone-tour
make manifest-proof
```
