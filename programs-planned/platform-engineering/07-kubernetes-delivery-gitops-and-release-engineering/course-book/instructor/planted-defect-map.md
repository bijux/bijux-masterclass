# Instructor planted-defect map

The ten defects cover mutable source, non-deterministic render, unsafe Helm hook, history rewrite, broad prune, stale readiness, plaintext secret, invalid canary, fleet deletion on missing source, and false production evidence. Each defect is tied to one proof script and one module checkpoint.

## Extended reader notes

Reveal defects only after the learner submits a hypothesis and evidence plan. Each defect targets a different layer: artifact identity, render dependency, hook replay, prune authority, field ownership, automation write scope, secret adoption, analysis sample adequacy, fleet source availability, and status overclaim.

A passing proof must be sensitive: temporarily enable the defect and show the named gate fail. Merely reading the descriptor does not prove the guard works. Restore the clean state and rerun the complete course proof before assessment.
