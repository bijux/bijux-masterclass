# Checkpoint — Final release defense

## Required evidence

- A complete release dossier.
- A compound incident timeline with role ownership.
- Categorical decisions for all supplied candidates.
- A no-op final reconciliation and exact Course 8 handoff.

## Decision defense

- Defend every controller and credential boundary.
- Explain the rollback frontier and protected-resource policy.
- State all not-executed production claims honestly.

## Progression gate

Course 7 is complete only when another engineer can reproduce the release decision and recover the delivery plane without relying on undocumented authority.
