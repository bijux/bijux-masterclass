# Checkpoint — Orientation

## Required evidence

- A passing predecessor manifest proof.
- An orientation report with exact tool versions and missing-tool classifications.
- Two distinct Git commit identities and one shared rendered-set digest.
- A selected primary implementation lane and a stated evidence class.

## Decision defense

- Explain why a Git commit is not a rendered manifest digest.
- Explain why a rendered manifest digest is not proof of cluster convergence.
- Name the Course 6 resources that ordinary prune logic may not remove.

## Progression gate

Do not begin Module 1 until the predecessor is immutable and the evidence limitations are written down.
