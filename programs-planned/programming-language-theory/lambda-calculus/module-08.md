# Module 8 – Simply Typed $\lambda$-Calculus (STLC): Core System

In this module we introduce the **simply typed $\lambda$-calculus (STLC)** as a typed refinement of the untyped $\lambda$-calculus (Modules 1–7). The goal is to **statically prevent** certain runtime pathologies of the untyped system (e.g. applying non-functions, many forms of “stuck” terms from Module 6) by assigning **types** to terms.

We work in a **Curry-style** presentation:

> $\lambda$-abstractions are *unannotated* ($\lambda x. t$), and types are assigned **by typing judgments** that infer the appropriate domain for abstractions.

The dynamic semantics ($\beta$-reduction) is still that of the untyped $\lambda$-calculus; types are a **static discipline** on top. Full safety (progress + preservation) and normalization are treated in **Module 9**. Here we focus on:

* syntax of **types** and **typing judgments**,
* the **declarative typing rules**,
* **structural properties** (weakening, substitution),
* a **syntax-directed (bidirectional) algorithmic system**, and
* **soundness, completeness**, and **uniqueness of types**.

## Prerequisites and Dependencies

* Module 1: syntax of $\lambda$-terms, $\alpha$-equivalence, substitution.
* Module 2: binding representations (we assume a named presentation and always work **modulo $\alpha$**).
* Module 3: $\beta$- and $\beta\eta$-reduction.
* Module 6: small-step semantics, stuck states (for intuition only).
* Module 7: explicit substitution is *not required* here; we use standard capture-avoiding substitution from Module 1.

Typed **operational** results (progress, preservation, normalization) are in Module 9.

Throughout this module we assume we are working **modulo $\alpha$-equivalence** and treat renaming of bound variables as inessential.

## Core 8.1 – Types, Terms, and Typing Judgments

### 8.1.1 Types

We fix a countable set of **base types**:
$$
\mathcal{B} = \{B, B', \dots\}\quad\text{(e.g. Bool, Nat, …)}.
$$

#### Definition 8.1 (Types)

The set of **types** is generated by:
$$
A ::= B \mid A \to A
$$
where $B \in \mathcal{B}$.

* $B$ is an **atomic** type.
* $A \to A'$ is a **function type**.

We adopt the usual **right-associative** convention:
$$
A_1 \to A_2 \to A_3 \equiv A_1 \to (A_2 \to A_3).
$$

### 8.1.2 Terms (recall)

The **term syntax** is that of the untyped $\lambda$-calculus (Module 1):

#### Definition 8.2 (Terms)

$$
t ::= x \mid \lambda x. t \mid t\, t
$$

where $x$ ranges over a countable set of variables.

We always work **modulo $\alpha$-equivalence** (bound variable names are irrelevant).

A term $t$ is **neutral** if it is a variable or an application $u\, v$ where $u$ is neutral (i.e., the head is a free variable).

### 8.1.3 Contexts and typing judgments

#### Definition 8.3 (Contexts)

A **typing context** (or environment) is a finite mapping
$$
\Gamma = x_1 : A_1,\dots,x_n : A_n
$$
with **pairwise distinct** variables $x_i$. We write $\mathrm{dom}(\Gamma) = \{x_1,\dots,x_n\}$.

We use:

* $\emptyset$ for the empty context,
* $\Gamma, x : A$ for extending $\Gamma$ with a fresh binding $x \notin \mathrm{dom}(\Gamma)$,
* $\Gamma(x)$ for the unique type associated to $x$ if $x \in \mathrm{dom}(\Gamma)$.

#### Definition 8.4 (Typing judgments)

A **typing judgment** has the form:
$$
\Gamma \vdash t : A
$$
and is read “under assumptions $\Gamma$, term $t$ has type $A$.”

Intuitively, every free variable of $t$ must appear in $\Gamma$ with the type prescribed by the judgment.

## Core 8.2 – Declarative Typing Rules

We now give the **declarative** typing system for Curry-style STLC. This is the system used for metatheory and logical reading (Curry–Howard).

### 8.2.1 Rules

Typing is defined as the **least** relation $\Gamma \vdash t : A$ closed under the following rules.

#### Rule 8.1 (T-Var)

If $x : A \in \Gamma$ then
$$
\Gamma \vdash x : A \quad\text{(T-Var)}.
$$

#### Rule 8.2 (T-Abs)

If $\Gamma, x : A \vdash t : B$ then
$$
\frac{ \Gamma, x : A \vdash t : B }{ \Gamma \vdash \lambda x. t : A \to B} \quad\text{(T-Abs)}.
$$

Here $x \notin \mathrm{dom}(\Gamma)$ (we can always $\alpha$-rename to ensure this).

#### Rule 8.3 (T-App)

If $\Gamma \vdash t_1 : A \to B$ and $\Gamma \vdash t_2 : A$ then
$$
\frac{ \Gamma \vdash t_1 : A \to B \quad \Gamma \vdash t_2 : A }{ \Gamma \vdash t_1\, t_2 : B } \quad\text{(T-App)}.
$$

These are the *only* typing rules in the core STLC (structural rules such as weakening are derivable lemmas, not primitive).

### 8.2.2 Simple examples

1. **Identity**: For any type $A$:
   $$
   \emptyset \vdash \lambda x. x : A \to A.
   $$
   Derivation:

   * By T-Var, $x : A \vdash x : A$.
   * By T-Abs, $\emptyset \vdash \lambda x. x : A \to A$.

2. **K combinator**: $\lambda x. \lambda y. x : A \to B \to A$.

   * $x : A, y : B \vdash x : A$ by T-Var.
   * $x : A \vdash \lambda y. x : B \to A$ by T-Abs.
   * $\emptyset \vdash \lambda x. \lambda y. x : A \to (B \to A)$, abbreviated $A \to B \to A$.

3. **Application**:
   $$
   f : A \to B,; a : A \vdash f\, a : B.
   $$

These will be used later when we relate typing to operational semantics (Module 9).

## Core 8.3 – Structural Properties and the Typed Substitution Lemma

We now prove the basic **structural lemmas** of STLC. These are purely static and do not involve evaluation.

### 8.3.1 Weakening

#### Lemma 8.5 (Weakening)

If $\Gamma \vdash t : A$ and $x \notin \mathrm{dom}(\Gamma)$, then for any type $B$:
$$
\Gamma, x : B \vdash t : A.
$$

*Proof.* By induction on the derivation of $\Gamma \vdash t : A$:

* **Case T-Var.** $t = y$ and $y : C \in \Gamma$. Then $y : C \in \Gamma, x : B$ as well, so $\Gamma, x : B \vdash y : C$ by T-Var. Since $C = A$, we have the result.

* **Case T-Abs.** $t = \lambda y. u$ with conclusion $\Gamma \vdash \lambda y. u : C \to D$, premise $\Gamma, y : C \vdash u : D$.
  Apply IH to the premise (note $x \neq y$ or $\alpha$-rename $y$ first) to get:
  $$
  \Gamma, x : B, y : C \vdash u : D.
  $$
  Then by T-Abs:
  $$
  \Gamma, x : B \vdash \lambda y. u : C \to D.
  $$

* **Case T-App.** $t = u\, v$ with premises $\Gamma \vdash u : C \to A$ and $\Gamma \vdash v : C$.
  By IH, $\Gamma, x : B \vdash u : C \to A$ and $\Gamma, x : B \vdash v : C$, hence by T-App:
  $$
  \Gamma, x : B \vdash u\, v : A.
  $$

All cases covered. ∎

### 8.3.2 Exchange (optional)

One can also show:

* **Exchange:** if $\Gamma_1, x:A, y:B, \Gamma_2 \vdash t : C$ then $\Gamma_1, y:B, x:A, \Gamma_2 \vdash t : C$.

Proof is similar by induction on derivations. We will not use exchange explicitly later, but it is standard.

### 8.3.3 Typed substitution

This is the key lemma relating typing and substitution.

#### Lemma 8.6 (Typed Substitution)

Let $x \notin \mathrm{dom}(\Gamma)$. If
$$
\Gamma, x : A \vdash t : B
\quad\text{and}\quad
\Gamma \vdash s : A,
$$
then
$$
\Gamma \vdash t[s/x] : B.
$$

*Proof.* By induction on the derivation of $\Gamma, x : A \vdash t : B$.

* **Case T-Var.** Two subcases:

  1. $t = x$. Then $B = A$ and $t[s/x] = s$. We have $\Gamma \vdash s : A = B$ by assumption, so done.

  2. $t = y \neq x$. Then $y : C \in \Gamma$ and $C = B$. Substitution does not affect $y$, so $t[s/x] = y$. By T-Var, $\Gamma \vdash y : C = B$.

* **Case T-Abs.** $t = \lambda y. u$, with premise:
  $$
  \Gamma, x : A, y : C \vdash u : D,
  $$
  and conclusion:
  $$
  \Gamma, x : A \vdash \lambda y. u : C \to D.
  $$
  Choose $y$ fresh so that $y \neq x$ and $y \notin \mathrm{FV}(s)$ ($\alpha$-rename if necessary). Then:

  * By weakening (Lemma 8.5) applied to the second assumption, $\Gamma, y : C \vdash s : A$.
  * By IH applied to the premise (with context $\Gamma, y : C$ and the same $s$),
    $$
    \Gamma, y : C \vdash u[s/x] : D.
    $$
  * By T-Abs,
    $$
    \Gamma \vdash \lambda y. (u[s/x]) : C \to D.
    $$
    And $\lambda y. (u[s/x])$ is exactly $(\lambda y. u)[s/x]$ by the definition of capture-avoiding substitution.

* **Case T-App.** $t = u\, v$ with premises
  $$
  \Gamma, x : A \vdash u : C \to B,\quad
  \Gamma, x : A \vdash v : C.
  $$
  By IH:
  $$
  \Gamma \vdash u[s/x] : C \to B,\quad
  \Gamma \vdash v[s/x] : C.
  $$
  Then by T-App:
  $$
  \Gamma \vdash u[s/x]\, v[s/x] : B.
  $$
  By definition of substitution on applications, $t[s/x] = u[s/x]\, v[s/x]$, so we are done.

All cases covered. ∎

This lemma is the static counterpart of $\beta$-reduction; it will be the main ingredient in the **preservation theorem** in Module 9.

## Core 8.4 – Algorithmic (Bidirectional) Typing

The declarative system is mathematically clean. To emphasize the algorithmic aspect and decidability, we introduce a **bidirectional** presentation, following the standard discipline:

* a **synthesis** judgment: $\Gamma \Rightarrow t : A$ (“$t$ *synthesizes* $A$”), which computes a type from the term, and
* a **checking** judgment: $\Gamma \Leftarrow t : A$ (“$t$ *checks against* $A$”), which verifies the term against a known type.

This system is equivalent to the declarative one for $\beta$-normal terms. In the Curry-style setting, abstractions check against a known arrow type (with the domain inferred or provided), while neutrals synthesize.

### 8.4.1 Bidirectional rules

We fix the following rules.

#### Synthesis rules

* **A-Var (synth):**
  $$
  \frac{ x : A \in \Gamma }{ \Gamma \Rightarrow x : A } \quad\text{(A-Var)}.
  $$

* **A-App (synth):**
  $$
  \frac{ \Gamma \Rightarrow t_1 : A \to B \quad \Gamma \Leftarrow t_2 : A }{ \Gamma \Rightarrow t_1\, t_2 : B } \quad\text{(A-App)}.
  $$

#### Checking rules

* **A-Abs (check):**
  $$
  \frac{ \Gamma, x : A \Leftarrow t : B }{ \Gamma \Leftarrow \lambda x. t : A \to B } \quad\text{(A-Abs)}.
  $$

* **A-Sub (check from synth):**
  $$
  \frac{ \Gamma \Rightarrow t : A }{ \Gamma \Leftarrow t : A } \quad\text{(A-Sub)}.
  $$

Intuition:

* Variables and applications synthesize: for applications, the function part synthesizes an arrow type, and the argument checks against the inferred domain.
* Abstractions check against a known arrow type: the domain is provided, and the body checks recursively under that assumption.
* Checking subsumes synthesis via A-Sub.

Algorithmically:

* To **synthesize** $\Gamma \Rightarrow t : A$: use A-Var for variables; for applications, synthesize the head and check the argument (A-App).
* To **check** $\Gamma \Leftarrow t : A$: if $t$ is a neutral (variable or application), synthesize and subsume (A-Sub); if an abstraction, match against $A = B \to C$ and check the body under $x : B$ (A-Abs).

This system is entirely **syntax-directed** and covers all terms. (In full type inference implementations, the domain for abstractions is inferred via unification over a polymorphic extension, but here we focus on the monomorphic STLC metatheory.)

### 8.4.2 Examples

1. Check the identity against $A \to A$:
   $$
   \emptyset \Leftarrow \lambda x. x : A \to A.
   $$
   Use A-Abs (with domain $A$):

   * Must check $x : A \Leftarrow x : A$.
   * A-Var gives $x : A \Rightarrow x : A$.
   * A-Sub: $x : A \Leftarrow x : A$.
     So $\emptyset \Leftarrow \lambda x. x : A \to A$.

2. Synthesize an application:
   $$
   f : A \to B,; a : A \Rightarrow f\, a : B.
   $$

   * A-Var: $f : A \to B \Rightarrow f : A \to B$.
   * Check $a : A$: A-Var gives $a : A \Rightarrow a : A$, then A-Sub: $a : A \Leftarrow a : A$.
   * A-App: $f : A \to B, a : A \Rightarrow f\, a : B$.

## Core 8.5 – Equivalence of Declarative and Algorithmic Systems; Uniqueness of Types

We now relate the two systems and prove that **types are unique** for typable terms.

### 8.5.1 Soundness and completeness of bidirectional typing

We first state precisely what we mean by equivalence. Note that the bidirectional system is complete for $\beta$-normal forms: in a $\beta$-normal term, the head of any application is neutral, ensuring synthesis applies directly.

#### Theorem 8.7 (Soundness of algorithmic typing)

1. If $\Gamma \Rightarrow t : A$ then $\Gamma \vdash t : A$.
2. If $\Gamma \Leftarrow t : A$ then $\Gamma \vdash t : A$.

*Proof.* By induction on the derivation of the algorithmic judgment.

1. For synthesis:

   * **A-Var:** Directly gives T-Var.
   * **A-App:** Assume $\Gamma \Rightarrow t_1 : A \to B$ and $\Gamma \Leftarrow t_2 : A$.

     * By IH on synthesis, $\Gamma \vdash t_1 : A \to B$.
     * By IH on checking, $\Gamma \vdash t_2 : A$.
     * By T-App, $\Gamma \vdash t_1\, t_2 : B$.

2. For checking:

   * **A-Abs:** Assume $\Gamma, x : A \Leftarrow t : B$; by IH on checking, $\Gamma, x : A \vdash t : B$, then T-Abs yields $\Gamma \vdash \lambda x. t : A \to B$.
   * **A-Sub:** If $\Gamma \Rightarrow t : A$, IH gives $\Gamma \vdash t : A$ directly.

∎

#### Theorem 8.8 (Completeness of algorithmic typing)

1. If $\Gamma \vdash t : A$ and $t$ is neutral, then $\Gamma \Rightarrow t : A$.
2. If $\Gamma \vdash t : A$ and $t$ is $\beta$-normal, then $\Gamma \Leftarrow t : A$.

*Proof.*

1. By induction on the structure of the neutral term $t$.

   * If $t = x$: T-Var gives $x:A \in \Gamma$, so A-Var gives $\Gamma \Rightarrow x : A$.
   * If $t = u\, v$: From T-App we have $\Gamma \vdash u : C \to A$ and $\Gamma \vdash v : C$ for some $C$. Since $t$ is neutral, $u$ is neutral, so by IH $\Gamma \Rightarrow u : C \to A$. By part 2 (proved below; note $v$ is $\beta$-normal as a subterm), $\Gamma \Leftarrow v : C$, hence $\Gamma \Rightarrow v : C$ by A-Sub. Then A-App yields $\Gamma \Rightarrow u\, v : A$.

2. By induction on the declarative derivation of $\Gamma \vdash t : A$, using that $t$ is $\beta$-normal.

   * **T-Var:** A-Var gives $\Gamma \Rightarrow x : A$, and A-Sub gives $\Gamma \Leftarrow x : A$.
   * **T-Abs:** Assume premise $\Gamma, x : C \vdash u : D$; since $t = \lambda x. u$ is $\beta$-normal, $u$ is $\beta$-normal, so by IH $\Gamma, x : C \Leftarrow u : D$. Then A-Abs gives $\Gamma \Leftarrow \lambda x. u : C \to D = A$.
   * **T-App:** Assume premises $\Gamma \vdash u : C \to A$ and $\Gamma \vdash v : C$. Since $t = u\, v$ is $\beta$-normal, $u$ must be neutral (no $\beta$-redex at head position), so by part 1 $\Gamma \Rightarrow u : C \to A$. Also, $v$ is $\beta$-normal (subterm), so by IH $\Gamma \Leftarrow v : C$. Then A-App yields $\Gamma \Rightarrow u\, v : A$, and A-Sub gives $\Gamma \Leftarrow u\, v : A$.

The mutual structure is standard in bidirectional typing: checking and synthesis are intertwined. For arbitrary (non-normal) terms, completeness holds after $\beta$-normalization (justified by strong normalization in Module 9). ∎

We extract the **practical corollary**:

> For STLC, given a context $\Gamma$, a term $t$, and a type $A$, it is **decidable** whether $\Gamma \vdash t : A$:
>
> * Normalize $t$ to $\beta$-normal form $t'$ (decidable by Module 9), then check $\Gamma \Leftarrow t' : A$ using the bidirectional judgment.
> * Accept if a derivation exists, reject otherwise.
>
> Termination follows by structural recursion on $t'$ (with type inference for abstraction domains via unification in implementations).

### 8.5.2 Uniqueness of types

We now show that STLC has **no ad-hoc overloading**: a term has at most one type in a given context.

#### Theorem 8.9 (Uniqueness of types)

If $\Gamma \vdash t : A$ and $\Gamma \vdash t : B$, then $A = B$.

*Proof.* We prove a strengthened version by induction on the structure of $t$: for all contexts $\Delta$ extending $\Gamma$ by a single variable $y : C$ (with $y \notin \mathrm{dom}(\Gamma)$), if $\Delta \vdash t : D$ and $\Delta \vdash t : E$, then $C = C$ (trivially) and $D = E$. The base case ($\Delta = \Gamma$) yields the theorem.

* **Case** $t = x$.
  Both derivations must end with T-Var, so $x : A \in \Gamma$ and $x : B \in \Gamma$, hence $A = B$. The strengthened hypothesis holds vacuously (no new variable).

* **Case** $t = \lambda y. u$.
  From the first derivation, by inversion on T-Abs, $A = C \to D$ for some $C, D$ and $\Gamma, y : C \vdash u : D$.
  From the second, $B = E \to F$ for some $E, F$ and $\Gamma, y : E \vdash u : F$.
  By the strengthened IH on $u$ under the common context $\Gamma, y : C$ and $\Gamma, y : E$ (noting the binders match by $\alpha$), we must have $C = E$ and $D = F$, hence $A = B$.

* **Case** $t = u\, v$.
  From the first derivation, by inversion on T-App,
  $$
  \Gamma \vdash u : C_1 \to A,\quad \Gamma \vdash v : C_1
  $$
  for some $C_1$.
  From the second:
  $$
  \Gamma \vdash u : C_2 \to B,\quad \Gamma \vdash v : C_2.
  $$
  Apply the (base) IH to the two derivations of $u$ to obtain $C_1 \to A = C_2 \to B$, hence $C_1 = C_2$ and $A = B$. (We could also apply the IH to $v$, obtaining $C_1 = C_2$.) The strengthened hypothesis follows similarly by applying the IH to the subderivations under $\Delta$.

All cases covered. ∎

As a consequence:

* For any fixed $\Gamma$ and $t$, there is **at most one** $A$ such that $\Gamma \vdash t : A$.
* If the algorithmic system can synthesize a type $A$ for $t$ in $\Gamma$, that $A$ is **uniquely determined**.

In the simple setting of STLC (no type variables, no polymorphism), this is the relevant notion of “principal type”.

## Summary and Suggested Exercises

In this module we:

* Fixed a **Curry-style** presentation of STLC: unannotated $\lambda$-terms, types assigned by judgments.
* Defined the syntax of **types**, **contexts**, and **typing judgments** (Defs. 8.1–8.4).
* Gave the **declarative typing rules** T-Var, T-Abs, T-App (Rules 8.1–8.3).
* Proved **weakening** (Lemma 8.5) and the **typed substitution lemma** (Lemma 8.6).
* Introduced a **bidirectional algorithmic system** (synthesis and checking) with rules A-Var, A-App, A-Abs, A-Sub.
* Proved **soundness** and **completeness** (for $\beta$-normal forms) of the algorithmic system relative to the declarative one (Theorems 8.7–8.8).
* Proved **uniqueness of types** (Theorem 8.9).

This sets up the static infrastructure needed for **safety** and **normalization** in Module 9, and for more advanced typing (products, sums, polymorphism) in later modules.

2. **Inversion exercises.**

3. **Typed substitution in detail.**

4. **Bidirectional typing examples.**

   * $t = \lambda x. x,; A = A \to A$,
   * $t = \lambda x. \lambda y. x y,; A = (A \to A) \to A \to A$,
   * $t = (\lambda x. x) (\lambda y. y),; A = B \to B$.

5. **Uniqueness variant.**
