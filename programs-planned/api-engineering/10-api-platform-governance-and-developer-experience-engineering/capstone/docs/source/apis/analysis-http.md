# Analysis HTTP API

**Contract:** `api:default/analysis-http` version 1.2.0  
**Authority:** Analysis Control Team  
**Protocol:** OpenAPI 3.1.2 executable baseline

Use this resource-oriented API for public project, dataset, run, and artifact workflows. Begin with the platform quickstart, authenticate through the documented resource-server profile, and preserve idempotency keys and entity tags exactly as described by the contract.

The platform publishes the contract by digest. It does not reinterpret request or response semantics. Compatibility evidence, security evidence, service objectives, performance evidence, support ownership, and active consumers are linked from the API product page.
