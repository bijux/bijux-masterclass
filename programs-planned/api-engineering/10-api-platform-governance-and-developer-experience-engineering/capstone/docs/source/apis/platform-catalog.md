# Analysis Platform Catalog API

**Contract:** `api:default/platform-catalog` version 1.0.0  
**Authority:** API Platform Team  
**Protocol:** OpenAPI 3.1

This API exposes platform-owned facts: catalog metadata, immutable release records, scorecards, documentation search, isolated sandbox sessions, runtime-drift evidence, and support routing. It explicitly excludes domain authorization and business-state mutation. The platform dogfoods the same ownership, publication, evidence, lifecycle, and documentation rules applied to other APIs.
