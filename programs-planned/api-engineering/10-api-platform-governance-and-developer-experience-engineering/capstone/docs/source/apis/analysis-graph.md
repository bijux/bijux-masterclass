# Analysis Graph API

**Contract:** `api:default/analysis-graph` version 1.0.0  
**Authority:** API Platform Team for graph composition; source services retain business ownership  
**Protocol:** GraphQL September 2025 profile

Use the graph for governed client-shaped reads and orchestration through persisted operations. Demand budgets, field ownership, exact error paths, authorization-before-I/O, and high-water cursors are mandatory. The graph gateway may compose capabilities but may not join private service databases or create a second domain model.
