# Artifact HTTP Capability

**Contract:** `api:default/artifact-http` version 1.0.0  
**Authority:** Artifact Team  
**Protocol:** OpenAPI 3.1

Use this internal capability for artifact metadata and bounded content retrieval. Preserve ownership checks, checksum evidence, entity tags, byte-range semantics, and streaming bounds. The graph and platform layers may discover and call this capability; they do not own artifact truth.
