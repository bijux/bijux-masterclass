# Course 9 → Course 10 handoff

This directory is the sanitized publication and governance boundary for Course 10. It contains the released graph contract, active client operations, ownership, demand policy, release policy, and evidence summary. It contains no source-service database, bearer credential, private signing key, or mutable business state.

Course 10 may catalogue, publish, generate, score, and govern these artifacts. It may not become the owner of the business facts they describe.
