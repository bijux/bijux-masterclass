# API Platform, Governance, and Developer Experience Engineering

This course completes the API Engineering program. The preceding nine courses
built correct contracts, durable services, security controls, operational
resilience, performance discipline, event interfaces, typed RPC, deliberate
service boundaries, and a governed GraphQL layer. Course 10 asks a different
question: **how can an organization make all of that work discoverable,
repeatable, supportable, and safe at scale without centralizing domain
ownership?**

The answer is not a larger gateway. It is not a prettier portal. It is not a
committee that reads every pull request. The answer is a platform product with
clear users, authoritative metadata, immutable contract releases, automated
policy, explicit human judgment, consumer-aware lifecycle management, maintained
golden paths, trustworthy artifacts, and measurable developer outcomes.

## The ten-course arc

```text
Specify → Implement → Defend → Operate → Scale
        → Integrate asynchronously → Engineer RPC
        → Distribute deliberately → Compose as a graph
        → Build the API platform
```

## How to use this book

Read [`start-here.md`](start-here.md), choose one primary implementation track,
and work through one numbered module per teaching day. Each chapter is complete
on its own. Exercises test transfer rather than memory. Labs force a platform
decision under controlled evidence. Checkpoints prevent progression when a
critical guarantee remains merely asserted.

The cumulative system is **Analysis API Platform 1.0**. It catalogs and publishes
the exact HTTP, event, RPC, and GraphQL contracts created earlier in the program.
It does not replace their owners.
