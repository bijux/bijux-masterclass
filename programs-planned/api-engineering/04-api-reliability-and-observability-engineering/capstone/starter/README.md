# Capstone Starter

The complete reference implementations are under `tracks/`. The starter provides worksheets and integration boundaries so learners do not destroy the reference while experimenting.

## Workflow

1. copy the primary-track reliability module or create a branch
2. complete the module worksheet
3. run focused proof
4. activate one planted defect
5. repair and retain regression

## Files

- `module-evidence-template.md`
- `fault-plan-template.yaml`
- `incident-timeline-template.yaml`
- `repair-plan-template.yaml`
