# Course 4 Handoff

This sanitized package is the immutable predecessor for **API Performance, Capacity, and Traffic Engineering**. It freezes the public contract, security profile, reliability semantics, SLI populations, trace topology, runbooks, and migration history established by Courses 1–4.

Course 5 may measure and revise numerical capacity, latency, and traffic budgets only through versioned evidence. It may not improve benchmark results by removing security controls, weakening durability, excluding provider-owned failures, changing eligible populations silently, or treating telemetry as business-state authority.

Verify `MANIFEST.json` and `MANIFEST.sha256` before use. The handoff intentionally excludes fixture secrets, private keys, local incident scratch data, generated telemetry, and environment-specific configuration.
