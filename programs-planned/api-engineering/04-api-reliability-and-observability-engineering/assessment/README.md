# Assessment Assets

Assessment is evidence-based rather than attendance-based. The directory contains the final rubric, checkpoint matrix, unseen transfer scenarios, evidence-submission template, and final-defense requirements.

A passing learner must show that the public API and security profile remain intact while reliability mechanisms fail safely. Numerical scores cannot compensate for a missing non-compensable gate such as unsafe retries, collector-dependent liveness, unbounded metric labels, destructive reconciliation, or an unowned incident.

Learner-facing assessment instructions live in each module checkpoint. This directory contains the program rubrics and machine-readable assessment support used by the release gates.
