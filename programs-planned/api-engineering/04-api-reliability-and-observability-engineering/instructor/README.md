# Instructor Assets

Instructor material defines facilitation, fault safety, reset procedures, answer policy, assessment, and adaptation rules. It is designed for self-learning as well as cohort delivery: no lab requires an instructor to reveal an undocumented trick.

Instructors may change pacing and synthetic workloads, but may not weaken API 1.2, security profile 1.0, durable-state authority, fault abort conditions, or proof boundaries. Any alternative implementation must preserve the same observable invariants and provide equivalent regression evidence.
