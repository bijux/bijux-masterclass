# Orientation Lab — Establish the Course 9 Baseline

## Objective

Verify the inherited boundary, record the study and implementation route, and prove that the dependency-light gates for **GraphQL Schema and Runtime Engineering** can reject one safe controlled defect before Module 1.

## Why this lab matters

The course asks: **How can clients select graph-shaped data and operations without moving business ownership, authorization, cost, or consistency into an uncontrolled gateway?** That question cannot be answered on top of altered predecessor bytes or ambiguous evidence. This lab creates a reproducible starting state and records the strongest claim the current environment can support.

## Setup conditions

- use a clean extraction or branch;
- keep predecessor and handoff directories read-only;
- confirm Python, Node.js, and Make are discoverable;
- create `work/orientation/course-09/` outside manifest-controlled payloads;
- list unavailable live infrastructure before running a proof.

## Hypothesis

The untouched Course 9 tree will pass its dependency-light entry proof. The controlled compose governed client-shaped capabilities defect will fail the predicted gate, and restoring the copied fixture will return the baseline to green without changing inherited bytes.

## Controlled action and investigation

1. Run the predecessor or entry-boundary proof and retain its summary.
2. Record the version state exactly as written in `course.json`.
3. Run the course structure and dependency-light core proof.
4. In scratch space, copy one persisted operation or field-ownership candidate, add unbounded fan-out or an ownerless field, and confirm the graph proof rejects it.
5. Predict the first failing gate before running it.
6. Restore the clean fixture and rerun the same route.
7. Record the primary/comparison language strategy.
8. State which claim still requires a standards-complete GraphQL runtime and live source services.

## Operational oracle

The incoming boundary remains byte-identical, the clean route passes, the copied defect is rejected by the predicted Course 9 gate, and the restored route passes again. No unavailable live proof is reported as successful.
