# Next-course handoff

Course 9 publishes `capstone/handoff/` for Course 10, **API Platform, Governance, and Developer Experience Engineering**.

The handoff contains the released Analysis Graph API 1.0 schema, ten active persisted operations, client ownership, field authority, query-budget policy, release policy, version ledger, and an evidence summary. It is a publication boundary rather than a database export.

Course 10 may build catalogues, documentation, SDK publication, scorecards, lifecycle workflows, and paved-road automation around these artifacts. It may not become the business owner of projects, runs, artifacts, notifications, or security decisions.

Verify it with:

