# Claims and evidence boundary

This course uses precise claims.

## Demonstrated by dependency-light proof

- schema and operation registry structure;
- exact Course 8 handoff integrity;
- global identifier and cursor invariants;
- per-request batching and cache isolation;
- query-depth, alias, fragment, list, and service-fan-out budgets;
- field authorization and tenant isolation;
- idempotent mutation delegation and expected-version handling;
- null propagation and partial-response semantics;
- persisted-operation identity and release compatibility;
- subscription resume and duplicate suppression;
- a real loopback HTTP graph-composition laboratory;
- Python and TypeScript semantic parity.

## Environment-backed, not claimed unless executed

- independent validation with GraphQL.js or graphql-core;
- live Strawberry and GraphQL Yoga servers;
- schema code generation with external registries and generators;
- a production subscription transport;
- Apollo Federation composition;
- strict MkDocs rendering;
- representative multi-service production load evidence.

The dependency-light engine is an instructional semantic core and persisted-operation executor. It is not presented as a complete implementation of the GraphQL September 2025 specification.
