# Analysis Runs Security Capstone

This directory extends the Course 2 Analysis Runs API with a security case, shared hostile vectors, Python and TypeScript security cores, framework adapters, fixture identity, security-state migrations, a controlled webhook receiver, incident/release exercises, and a public outgoing handoff.

Run all commands from the course root. The immutable predecessor is under `predecessor/`; do not modify it to make a security test pass.
