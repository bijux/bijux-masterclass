# Assessment Rubric

| Dimension | Weight | Distinction evidence |
|---|---:|---|
| Security case | 20 | prioritized, traceable, assumption-aware |
| Edge and identity | 15 | raw-message ownership and complete validation profile |
| Authorization | 15 | default-deny operation/resource/field policy |
| Input and outbound | 20 | shared hostile vectors and environment boundaries |
| Secrets, audit, abuse | 10 | bounded, non-rendering, deterministic controls |
| Verification and supply chain | 10 | planted-defect sensitivity and honest reports |
| Incident defense | 10 | containment, compatible release, updated case |
