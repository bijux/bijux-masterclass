# Evidence and production claims

This course teaches production-grade engineering mechanisms. It does not label a local educational environment as production-proven.

## Executed dependency-light claims

The packaged proof can establish:

- proto source structure and semantic invariants
- checked descriptor inventory
- cross-language message, integer, status, retry, stream, security, and lifecycle vectors
- deterministic Python live gRPC behavior where `grpcio` is installed
- TypeScript semantic and generated-interface compatibility through the dependency-light track
- migration and release fixture integrity
- reader-facing course structure and manifest integrity

## Environment-backed claims

The following require the named external environment and are reported as not executed when absent:

- independent `protoc` generation and binary descriptor comparison
- Buf lint and breaking checks
- grpcurl reflection and live method invocation
- live mTLS and certificate rotation
- PostgreSQL concurrency, persistent idempotency, lease fencing, and migration coexistence
- complete grpc-js/proto-loader network implementation
- multi-instance resolver/load-balancer topology
- strict MkDocs rendering

A present script is not evidence that the environment-backed proof ran.
