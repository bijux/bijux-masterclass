# Course 6 → Course 7 handoff

This immutable package carries the governed event API into the next API Engineering course. It preserves HTTP API 1.2 and adds Event API 1.0, AsyncAPI 3.1.0, CloudEvents 1.0, event profile 1.0, and database revisions 010–012.

The next course may add a typed RPC boundary, but it must not silently change event meaning, partition identity, replay policy, or consumer effect identity.
