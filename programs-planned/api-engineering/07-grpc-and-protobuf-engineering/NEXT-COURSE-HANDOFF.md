# Course 8 handoff

Course 7 exports a sanitized handoff for **Distributed API Architecture and Microservices Engineering**.

The handoff contains:

- Analysis RPC API 1.0 proto and descriptor inventory
- method catalogue and consumer declarations
- interaction decision and service ownership records
- public HTTP and Event API boundary digests
- status, deadline, retry, streaming, security, and lifecycle profiles
- migrations 001–015
- compatibility and release evidence
- critical journeys and SLO references
- service-boundary dossier with explicit keep/split hypotheses
- rollback and unresolved evidence boundaries

Course 8 must challenge, not merely accept, the proposed boundaries.
