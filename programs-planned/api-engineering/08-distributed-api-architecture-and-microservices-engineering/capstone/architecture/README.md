# Architecture dossier

These files are versioned architecture inputs used by the course proof. They are not generated diagrams. Every service, fact, edge, saga, security rule, release rule, and extraction phase has a named owner or decision.

A change to one file should be reviewed against the others. For example, adding a service requires service-catalog ownership, data authority or an explicit non-data role, dependency edges, release support, security policy, and extraction or creation evidence.
