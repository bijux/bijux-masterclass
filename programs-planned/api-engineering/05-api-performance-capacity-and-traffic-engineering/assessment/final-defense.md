# Final defense

The learner has 25 minutes to defend a performance release dossier and 20
minutes to answer adversarial review questions.

## Required demonstration

- identify the critical workload and evidence class;
- explain open or closed demand behavior;
- reconcile every outcome population;
- show the baseline variability and comparison rule;
- locate the first limiting resource using at least two independent signals;
- explain why the proposed change should move those signals;
- demonstrate preserved API, security, and reliability behavior;
- quantify side effects, operational cost, and rollback conditions;
- reject one faster-but-wrong candidate;
- state what remains unknown.

The defense fails if the learner substitutes tool output for causal reasoning.
