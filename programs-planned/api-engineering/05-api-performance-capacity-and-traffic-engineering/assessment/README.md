# Assessment model

The course uses non-compensable evidence gates. A high written score cannot
compensate for a candidate that violates authorization, drops outcomes, or uses
an incomparable environment.

| Area | Points |
|---|---:|
| Ten module checkpoints | 30 |
| Workload and benchmark design | 15 |
| HTTP, database, and runtime evidence | 15 |
| Queueing, caching, and traffic controls | 15 |
| Capacity model | 10 |
| Final release dossier and defense | 15 |
| **Total** | **100** |

Passing requires 85/100 **and** every non-compensable gate in
`completion-rubric.md`.
