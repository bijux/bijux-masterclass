# Course 5 outgoing handoff

This directory contains the minimum sanitized evidence needed by Course 6,
Event-Driven API Engineering. It preserves API 1.2, security profile 1.0,
reliability profile 1.0, and performance profile 1.0.

The handoff intentionally excludes raw benchmark samples, hostnames, secrets,
access tokens, private dataset contents, transient traces, and machine-specific
paths. Event-driven work must not begin by discarding the workload, backpressure,
capacity, and correctness lessons established here.
