# Facilitation notes

## Daily rhythm

- retrieval exercise from the previous module;
- one governing concept demonstrated on the capstone;
- one mechanism workshop in the primary language;
- one comparative review in the second language;
- one controlled experiment;
- one evidence review and checkpoint.

## Common interventions

When a learner says “CPU is high,” ask which process, interval, workload,
utilization denominator, and queue state. When a learner says “the index made it
faster,” ask which parameters, rows, buffers, write costs, and migration lock
were observed. When a learner says “cache it,” ask who owns invalidation and
whether two principals may receive different bytes for the same resource ID.
