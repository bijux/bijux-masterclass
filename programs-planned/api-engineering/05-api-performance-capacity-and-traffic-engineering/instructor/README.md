# Instructor guide

Course 5 is taught as ten experiments, not ten lectures. The instructor protects
three boundaries:

1. performance is never allowed to override inherited correctness;
2. environment-dependent evidence is never represented as executed when the
   environment is absent;
3. learners must explain the mechanism connecting a code or configuration
   change to observed resource behavior.

Require one primary implementation track. Use the comparative track for code
review and vector parity, not duplicate typing. During reviews, ask which metric
would falsify the learner's bottleneck hypothesis. A candidate with no possible
falsifier is not ready for benchmarking.
