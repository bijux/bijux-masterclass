# 02. Programming Languages: Object-Oriented Programming

**Program code:** `OOP`

**Purpose:** Develop precise command of object models, object-oriented abstraction, polymorphism, composition, and maintainable object-oriented implementation across languages.

**Level-II professional outcome:** Ready to design, implement, test, review, and evolve substantial object-oriented systems in Java-, C#-, C++-, Python-, or similar ecosystems.

**Prerequisites:** Programming Languages & Semantics Level I; data structures; testing fundamentals.

**Primary ownership:** object models; encapsulation; class and prototype systems; subtyping and dispatch; composition and inheritance; object lifecycles; OO generics; OO concurrency; OO runtime behavior; large-scale OO code.

**Explicit exclusions:** general domain modeling (Program 09); pattern catalogues (Program 11); system-wide architecture (Program 12); general programming-language semantics (Program 01).
