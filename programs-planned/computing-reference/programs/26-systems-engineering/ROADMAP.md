# 26. Systems Engineering

**Program code:** `SYSENG`

**Purpose:** Develop a disciplined, lifecycle-wide method for defining, modeling, integrating, verifying, operating, and evolving complex software-intensive and cyber-physical systems.

**Level-II professional outcome:** Ready to work as a systems engineer on complex products or platforms, managing stakeholder needs, requirements, interfaces, trade studies, risk, verification, and system evolution.

**Prerequisites:** software and computer-systems foundations; basic probability and statistics; experience with multidisciplinary projects.

**Primary ownership:** systems thinking; stakeholder needs; requirements engineering; functional and physical architecture; model-based systems engineering; interfaces and integration; trade studies; reliability and safety; verification and validation; system lifecycle and systems of systems.

**Explicit exclusions:** software component design (Program 09); software architecture detail (Program 12); project delivery method ownership (Program 10); cloud and platform implementation (Programs 29-30).
